## 읽는 법

- `web/puzzles.js`에는 옛과 새의 가운데(가중치 0.5)를 넣었다 — 두 추정 모두 아직 실제 시도로 맞춰지지 않았으므로. 보는 AI만 쓰려면 `--write --weight 1`.
- 두 턴 퍼즐은 레이팅을 그대로 뒀다 — 둘째 턴을 첫 길 하나가 남긴 자리에서만 읽어 아직 거칠다(위 표의 두 턴 숫자도 그만큼 덜 믿을 것).
- **새 > 옛**: 답이 사람 눈에 잘 안 보이거나(볼 확률 낮음) 그림이 실제와 어긋나(그림이 어긋난 각 큼) 사람이 노린 곳이 빗나간다 — 옛 AI가 쉽게 본 퍼즐.
- **새 < 옛**: 넓은 길이 여럿이라 사람이 쉽게 찾는다 — 옛 AI가 길 하나의 어려움으로 매긴 퍼즐.
- 숫자는 손으로 정한 값(`MIND`)이다. 실제 시도가 쌓이면 Fit 워크플로로 맞춘다(계획 8-3).
