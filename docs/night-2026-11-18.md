# 밤 작업 2026-11-17 → 18: AI 평가 엔진 + 게임 리뷰

소유자 결정(11-17 23:34 ~ 23:56, 이대로 따른다 — 밤에는 질문하지 않는다, 예약된 작업은 바꾸지 않는다):

- 이 AI는 게임의 기반. 대충 넘어가지 말 것. 테스트로 확인하며 간다.
- 등급 5개: 예술 / 좋음 / 무난 / 아쉬움 / 실수. **환상적은 뺀다.** 예술은 연보라.
  아이콘은 체스닷컴 같지 않게, 당구 기호로 직접 그린다(동그라미 + 아이콘).
- **요행**은 등급이 아니라 딱지: 샷은 그 자체로 평가하고, 요행이면 딱지를 따로 붙인다.
- 쉬운 길을 두고 어려운 길을 골라 성공 + 남은 자리 좋음 → 예술.
- 예술은 실용성(남은 자리)이 낮으면 안 뜬다. 예술·실용 점수는 숫자로 겉에 안 나온다.
- **초보 보정 없음**: 난이도는 레이팅과 상관없는 고정된 기준 손으로 잰다.
- 경기 끝나면 결과 화면에 요약만: 등급별 개수(나 vs 상대) + **샷 성공 확률** + **경기력 레이팅**. 정확도·흐름 그래프 없음.
  그 아래 '게임 리뷰' 버튼(한 판 더 위). 나중에 회원제(당구 에듀케이션)로 상세 리뷰를 묶을 수 있게 요약/상세를 나눈다.
- 리뷰 화면: 왼쪽 트레이를 당구대로 꽉 채움(샷 재생), 오른쪽 차콜 패널 = 통계 → 샷 목록 → 고른 샷 해설 + '더 좋은 샷 보기'.
  해설은 의도를 읽어서: "길은 맞았는데 조준이 아쉬웠다", "더 쉬운 길이 있었다", 예술 = "아름답습니다…".
- 4구 / 3쿠션 / 8볼 / 9볼 (+스누커) 기준을 따로 둔다.
- 실시간 연출(잔상·박수) 없음. 봇 대사만: 내가 방금 친 샷의 등급에 반응, 한 판 안에서 같은 말 반복 금지.
- 봇 샷 선택을 새 엔진으로 바꾸는 건 **다음 밤**.
- 메인 메뉴: 카드 안에 은은하게 흐르는 그라데이션만.
- 일라이자 그림 받음(`/mnt/user-data/uploads/e0496aa2-image.png`). 루이자는 그림 올 때까지 잠금.
  잠금 표시는 이모지 자물쇠 말고 직접 그린 아이콘.
