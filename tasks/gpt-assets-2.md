# 작업: 새 스킨용 그림·소리 묶음 (GPT용)

너는 GitHub 저장소 `coooxroad/8-Ball`(3D 당구 게임 CUE)에 **그림과 소리 파일만** 더한다. 이것들을 쓰는 코드(트레일 효과,
테이블 재질, 감자 구분, 큐)는 Claude가 같은 때 만든다. 그래서 **아래 파일 이름과 규격을 정확히** 지켜야 한다.
먼저 `AGENTS.md`(특히 7·8절)와 `tasks/gpt-skins.md`(3절 그림 공통 규칙)를 읽는다.

## 0. 범위
- 넣는 곳: `web/tex/`, `web/ui/`, `web/sound/`. 그 밖의 파일(`web/content/`, 코드, 검사)은 **고치지 않는다** — 데이터 연결은 Claude가 한다.
- PR #8(알감자·볼링공·광선검)은 Claude가 직접 합친다. 그 PR은 더 고치지 않아도 된다.
- 브랜치 `gpt/assets-2`, PR 제목 `자산: 새 스킨 그림·소리 묶음`. 본문에 파일마다 미리보기 링크와 쓴 프롬프트, 소리는 합성 방법.
- 실제 브랜드·캐릭터·로고·글꼴 이름을 흉내 내지 않는다. 만화 효과음 글자는 직접 그린 한글.
- 그림: WebP quality 86~88, 투명이 필요한 것은 알파 포함. 소리: WAV 44.1kHz 16bit 모노, 피크 -1dBFS 이하, 앞 무음 없이,
  외부 음원 없이 직접 합성(PR에 방법), 각 40KB 이하.

## 1. 알감자 공 — 4구 공 구분용 표면 (A안: 감자 종류로 구분)
기존 `ball-potato.webp`(PR #8의 갈색 껍질)는 그대로 쓴다. 더할 것:
| 파일 | 내용 |
|---|---|
| `web/tex/ball-potato-white.webp` | 껍질을 깐 하얀 감자 속살(크림색, 칼로 깎은 면이 살짝 보임) |
| `web/tex/ball-potato-gold.webp` | 노란 황금 감자 껍질(밝은 노랑, 감자 눈) |
| `web/tex/ball-potato-red.webp` | 빨간 홍감자 껍질(진한 붉은 껍질, 감자 눈) |
세 장 모두 1024×512, 2:1 등장방형, 좌우 이음매 없음, 극 근처 조용히, 조명 없이 평평한 무광 색(그림자·광택을 굽지 않음).

## 2. 트레일 소리 (트레일 그림은 만들지 않는다)
소유자 결정: **트레일 효과와 수영장 물은 코드로 그린다**(움직여야 하고, 구조상 안전). 그래서 `fx-chalk-*`, `fx-star`, `fx-puff`,
`fx-ink`, `fx-flame`, `fx-splash`, `fx-ripple`, `pool-water`, `pool-tiles` 그림은 **넣지 않는다**. 이미 그렸으면 PR에서 뺀다.
소리만:
| 파일 | 내용 |
|---|---|
| `web/sound/fx-fart.wav` | 짧고 우스운 "뿡"(0.3~0.5초), 지저분하지 않게 장난감 같은 소리 |
| `web/sound/fx-fire.wav` | 짧은 "화르륵"(0.4초) |
| `web/sound/fx-splash.wav` | 짧은 "첨벙"(0.3초) |
| `web/sound/fx-chalk.wav` | 칠판에 분필 "톡"(0.15초) |

## 6. 검사
`AGENTS.md` 2절의 네 가지. 그림·소리만 더하므로 실패하면 파일 이름이나 형식 문제다. 실기기 확인은 "확인 못 함"으로 적는다.
