# 다른 AI에게 맡기는 일

소유자가 GPT(또는 Gemini 등)에게 일을 맡길 때 쓰는 작업 지시서. 파일 하나 = 작업 하나.
소유자는 해당 파일의 내용을 **통째로** 붙여 넣고 "이대로 해 줘"라고만 하면 된다.

| 파일 | 일 | 건드리는 곳 |
|---|---|---|
| `gpt-skins.md` | 스킨(큐·공·테이블·트레일·장갑) 추가, 스킨별 소리 | `web/content/`, `web/ui/`, `web/tex/`, `web/sound/` |
| `CUE-prompts-bots-art.md` | 그림(소유자가 GPT 이미지로): 봇 21명 그림, 그림체 g(유화 + 애니), 투명 배경 | `web/ui/bot-<id>.webp` (Claude가 넣음) |
| `CUE-prompts-bots-art2.md` | 그림 2차(11-17 21:00): 남은 5명: 다리야★★·루이자★·아나☆·프리야☆·미고(필리핀 12살) — 다은·올레·프레데릭·일라이자는 소유자가 이미 뽑음. 통째로 붙여 넣고 마음에 든 그림 한 장을 같이 올림. 머리색·인종이 다 다르게, 입은 다물게 | `web/ui/bot-<id>.webp`, 받으면 `BOT_FRAME` 줄 갱신 |
| `CUE-prompts-style-test.md` | 그림(소유자가 GPT 이미지로): 봇 그림체 고르기 — 한 인물을 6가지 그림체로 | 고른 그림체로 봇 프롬프트를 다시 씀 |
| `CUE-prompts-bots-props.md` | 그림(소유자가 GPT 이미지로): 봇 초상 15장, 메뉴의 수건·식물 고해상도 — zip으로 Claude에게 | `web/ui/` (Claude가 넣음) |
| `gpt-assets-3.md` | 소리 묶음 3: 통기타·플루트·크리스탈·농구공 타격음 (당구드롭 효과음은 필요 없어졌다) | `web/sound/` |

끝난 작업의 지시서는 지운다(퍼즐·바리케이드·사람 같은 상대 v1·v2·자산 묶음 2·레슨 — 모두 합쳐졌거나 형식이 바뀌었다; `git log`에 남아 있다).

PR이 오면 Claude가 검토하고 합친다. 소유자는 PR 주소만 Claude에게 알려 주면 된다.
