# 작업: CUE 소리 묶음 3 — 당구드롭과 새 스킨 (GPT용)

너는 GitHub 저장소 `coooxroad/8-Ball`의 3D 당구 게임 CUE에 **효과음**을 만든다. 코드는 Claude가 붙인다. 소리 파일만
`web/sound/`에 넣고 PR을 연다(브랜치 `gpt/sounds-3`). 형식: `.wav`, 44.1kHz, 모노, 앞뒤 무음 30ms 이하, 피크 −1dBFS,
길이는 아래 표대로. 저작권이 있는 소리·음악을 잘라 쓰지 않는다(직접 합성하거나 CC0만, PR에 출처).

## 당구드롭 (브롤스타즈의 스타드롭처럼 당구공을 두드려 등급을 올리는 화면)
| 파일 | 길이 | 소리 |
|---|---|---|
| `fx-drop-tap.wav` | 0.25s | 당구공을 손가락으로 톡 두드림 + 살짝 흔들리는 딸깍. 실패(등급 그대로)일 때도 이 소리 |
| `fx-drop-up.wav` | 0.6s | 등급이 오를 때: 짧은 반짝 휙 + 밝은 종소리 한 음(높아지는 느낌) |
| `fx-drop-up-big.wav` | 1.0s | 전설·시크릿으로 오를 때: 위보다 크고 화려하게, 끝에 잔향 |
| `fx-drop-open.wav` | 0.9s | 마지막에 공이 터지며 열림: 유리구슬 깨지는 듯한 반짝임 + 짧은 팡파르 세 음 |
| `fx-drop-coin.wav` | 0.5s | 코인이 쏟아짐(짤랑짤랑) |
| `fx-drop-dia.wav` | 0.5s | 다이아(맑은 크리스탈 딩) |

## 새 스킨 소리 (공·큐가 칠 때 원래 소리 대신)
| 파일 | 길이 | 소리 |
|---|---|---|
| `guitar-strike.wav` | 0.6s | 통기타 몸통으로 공을 칠 때: 나무 몸통의 둥 + 개방현이 살짝 울림 |
| `flute-strike.wav` | 0.4s | 은 플루트 관으로 칠 때: 금속관 팅 + 아주 짧은 바람 소리(휘슬) |
| `crystal-click.wav` | 0.35s | 크리스탈 공끼리 부딪힐 때: 맑은 유리 딩(너무 높지 않게) |
| `basketball-hit.wav` | 0.3s | 농구공끼리: 고무공 퉁 |
