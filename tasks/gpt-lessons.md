# 작업: CUE 레슨 4권 채우기 (GPT용)

너는 GitHub 저장소 `coooxroad/8-Ball`의 3D 당구 게임 CUE에 **레슨**을 만든다. 레슨은 종목별 교본 4권(3구·4구·8볼·9볼)에
들어간다. 틀(화면, 단계, 판정, 서버 확인, 보상)은 다 되어 있고, **레슨 목록만** 비어 있다. 8볼에는 본보기로
`e-straight`(정면 넣기) 하나가 들어 있다. 코딩을 모르는 소유자가 태블릿으로 결과를 본다.

## 0. 먼저 읽을 것
1. `AGENTS.md` 전체. 여기 적힌 규칙이 이 지시서보다 우선이다.
2. `web/drills.js` — 레슨 형식(맨 위 주석)과 본보기 `e-straight`. `make()`, `judge()`, `LEVELS`(5), `COURSES`.
3. `web/test/run.js`의 drills 블록 — 모든 레슨의 시범 샷을 모든 단계·모든 테이블 크기(bar, club, pro, pub)에서 쳐 보고,
   레슨이 요구한 대로 안 되면 실패한다. **이 검사가 통과해야 한다.**
4. `server/src/check.js`의 `playLesson` — 서버가 5단계 성공 샷을 다시 쳐서 확인하는 방법(씨앗으로 같은 배치를 다시 만든다).
5. `web/physics.js` 끝의 반환값 — `P.POCKETS`(포켓 위치·입구 ax/ay·방향 nx/ny), `P.HL`, `P.HW`, `P.R`, `P.isFree`.

## 1. 일의 범위
- 만들 곳: `web/drills.js`의 `list`에 레슨 추가. 필요하면 `drills.js` 안에 작은 도우미 함수.
- 건드리면 안 되는 곳: `web/physics.js`, `web/game.js`, `web/app/`, `server/`, `.github/`, `judge()`의 기준을 느슨하게,
  `web/test/run.js`의 검사를 약하게. 판정에 새 조건이 필요하면 `need`에 항목을 더하는 제안만 PR 본문에 적는다.
- **id는 한번 정하면 바꾸지 않는다**(서버가 8볼 보상을 줄 때 id로 확인하고, 기기에 저장된 진행도도 id로 남는다).
  접두어: 3구 `t-`, 4구 `f-`, 8볼 `e-`, 9볼 `n-`.
- 브랜치 `gpt/lessons`. 종목마다 커밋을 나눈다(3구 / 4구 / 8볼 / 9볼).

## 2. 레슨 한 개의 형식
```js
{ id: 'e-stop', name: '스톱샷', d: '카드에 나오는 한 줄', tip: '힌트 버튼에 나오는 말',
  vol: 'eight', course: '기본기',            // vol: 'three' | 'four' | 'eight' | 'nine', course: COURSES 중 하나
  make(P, t, rnd, vOf) { ... return { cue: [x, y], balls: [[id, x, y], ...], need: { pot: 1 }, demo: { angle, power, a, b }, zone? } } }
```
- `t`: 0(1단계)~1(5단계). 단계가 오를수록 멀게, 각을 크게, 원(zone)을 작게.
- `rnd`만 쓴다(**`Math.random` 금지**): 같은 씨앗이면 같은 배치가 나와야 서버가 확인할 수 있다.
- 배치가 마음에 안 들면 `null`을 돌려준다(다시 불린다). 공은 천 위, 서로 겹치지 않게(`P.isFree` 참고).
- `need`: `pot`(그 번호가 들어가야), `any`(아무 공이나 n개), `bank`(그 번호가 쿠션을 맞고 들어가야), `only`(그 공만 맞혀야).
  `zone: { x, y, r }`: 샷이 끝났을 때 큐볼이 이 원 안에 있어야(포지션 연습).
- `demo`: 정답 샷 하나. `power`는 0~1(세기 게이지), `a`·`b`는 당점 −1~1(오른쪽·위가 +).
  `run.js`가 이 샷으로 매번 성공하는지 본다. 큐볼이 빠지면 실패다.
- 캐롬(3구·4구) 레슨은 아직 판정이 포켓볼용이라 `need` 대신 `carom: { hit: [..], cushions: n }` 같은 새 형식이 필요하다.
  **3구·4구는 형식 제안과 레슨 설계(이름·설명·배치 그림을 말로)만** PR 본문에 쓰고, 코드는 8볼·9볼만 만든다.

## 3. 만들 것
### 8볼 (12개 안팎) — 다 깨면 보상이 있다(3,000 코인 + 브레이크 큐, 서버가 확인해서 줌)
- 기본기: 정면 넣기(있음), 얇게 맞혀 넣기(컷샷), 스톱샷, 밀어치기(팔로), 끌어치기(드로)
- 큐볼 다루기: 원 안에 세우기(zone), 쿠션 맞고 포지션, 다음 공 각 만들기(공 두 개, 1번 넣고 2번 치기 좋은 원 안으로)
- 응용: 뱅크샷(`bank`), 키스샷, 콤비네이션(1번으로 2번 넣기), 8번 마무리(8번 하나 남은 상황)
### 9볼 (8개 안팎)
- 기본기: 가장 낮은 번호 먼저 맞히기(`only`), 9번 콤보로 넣기 · 큐볼 다루기: 다음 번호로 포지션 · 응용: 세이프티(맞히고 숨기기 — 판정 제안만)

## 4. 확인
1. `node web/test/run.js` — 다 통과(레슨 수가 늘면 시간이 조금 늘어도 된다).
2. `sh web/build.sh` 후 `node web/tools/check.js`.
3. `cd server && npm test` — `lessons:` 줄이 8볼 레슨 수와 함께 통과해야 한다(모든 8볼 레슨의 5단계 시범 샷으로 보상을 받아 본다).
4. PR 본문 첫 줄에 건드린 파일 목록. 레슨마다 한 줄 설명(무엇을 연습하나, 1단계와 5단계가 어떻게 다른가).
