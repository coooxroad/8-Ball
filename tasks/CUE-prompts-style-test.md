## When a style is picked

Claude writes the full prompt file for the bots in that style: for each bot a character sheet first (the same face from the
front and three-quarters, so GPT keeps her the same), then the pictures for each relationship stage (the same person, the
expression and outfit changing), transparent background, sizes for the card and the slate.
