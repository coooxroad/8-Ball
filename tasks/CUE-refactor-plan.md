## 지킬 것

- **UI 99% 그대로**: 보이는 모습·움직임·문구를 바꾸지 않는다. 바뀌면 안 되는 것을 바꿨는지 이렇게 확인한다.
  - CSS를 손대면 `web/tools/compare/styles.js`로 전후 계산된 스타일 비교 — 차이 0(의도한 것만).
  - 3D를 손대면 `web/tools/compare/frames.js`로 프레임 md5 비교.
  - 화면 흐름을 손대면 스크린샷(태블릿 1280x800, 폰 가로 915x412)을 전후로 보고, 브라우저 검사(`web/test/browser/*.js`) 통과.
- **동작 그대로**: 물리·규칙·판정 결과가 바뀌면 안 된다(`PHYS_V` 그대로). core(web/*.js, ai/, content/)를 고치면 `node web/test/run.js`, 판정·물리면 `node web/test/judge.js`, 서버면 `cd server && npm test`.
- AGENTS.md의 규칙: 폴더 이어붙이기(맨 위 이름 하나뿐, 순서), 인라인 스크립트 금지, 주석은 영어로 "왜", `app/src/main/assets/` 손대지 않기, 릴리스·서명 단계 손대지 않기.
- 작게 나눠 커밋하고 `main`에 바로 푸시(CLAUDE.md). 푸시 전 `git pull --rebase`. 푸시 뒤 CI(`gh run list -R coooxroad/8-Ball`)가 초록인지 본다.
- 소유자 취향이 걸린 것(모양이 바뀌는 최적화, 자산 삭제)은 하지 말고 아래 "제안"에 적는다.

## 라운드별 할 일 (S 스파게티 · P 다듬기 · O 최적화)

### 라운드 1
- **S1-a 결과 흐름 나누기**: `50-match.js` `finish()`를 "결과 데이터 만들기"와 "그리기(점수표·영수증·레이팅 단계·하이라이트)"로 나눈다. `50-outro.js`의 색종이·승리 카메라를 `50-celebrate.js`로.
- **S1-b 죽은 코드 치우기**: 메뉴 진단, 유리 케이스 나사·`gz-holo-all`, 영수증이 덮은 가로 결과 슬레이트 CSS(관전 결과가 그걸 쓰는지 먼저 확인), 지운 설정의 prefs 키(불러올 때 지움), 낡은 주석.
- **P1-a 공용 도우미**: mm:ss·두 자리·ease·clamp·티어 색을 `00-state.js` 한 곳에.
- **P1-b 문서**: AGENTS.md 코드 지도(38-glass3d, 50-receipt, 50-rise, 50-celebrate), 낡은 결과 설명 고치기, `web/tools/measure.js` 소개.
- **O1-a 가만히 있는 화면의 일**: 메뉴 646 ms·상점 297 ms의 출처를 찾아(성능 프로파일) 안 보이는 것·가려진 것은 멈춘다(시트가 덮을 때, 탭이 숨었을 때, 화면 밖 카드). 보이는 움직임은 그대로.
- **O1-b 유리 케이스 렌더러**: 메뉴 정지 그림 뒤 WebGL 컨텍스트·환경맵을 계속 쥐고 있음 → 필요할 때만, 크기·해상도 점검.
- **O1-c 결과 화면 비용**: 색종이 캔버스(dpr 2 전체 화면), 승리 카메라 동안 매 프레임 직접 그리기, 영수증 MutationObserver — 끝나면 확실히 멈추는지.

### 라운드 2
- **S2-a 책상(메뉴·내 장비·상점) 그리기**: `32-desk`·`35-desk-shelves`·`36-desk-paint`·`37-desk-menu`의 서로 부르기 정리, 탭마다 DOM을 다시 만들지 않고 재사용(로드맵 6의 "탭 전환 DOM 재사용").
- **S2-b CSS 겹친 규칙 합치기**: 위 "훑어본 것"의 겹친 선택자들을 하나로(`web/tools/cssmerge.py`), `styles.js` 비교 차이 0.
- **P2-a**: `!important` 줄이기, z-index 표, 쓰이지 않는 클래스(조합 이름 확인 후) 지우기.
- **O2-a 시작 시간**: data URI 1.09 MB — 앱이 페이지를 어떻게 여는지(파일/에셋 로더) 확인하고, 파일로 뺄 수 있으면 빼거나 필요할 때만 풀기. 메뉴까지 시간 비교.
- **O2-b 문장 데이터**(봇 대사 54 KB, 리뷰 문장 79 KB): 파싱 비용을 재고 의미 있으면 나중에 읽기.
- **O2-c 이미지**: 쓰는데 크기만 큰 그림 확인(화질 그대로 재압축만). 봇 그림 1.6 MB는 지금 디버그에서만 보임 → 지우지 말고 제안으로.

### 라운드 3
- **S3-a 게임 루프·입력**: `90-loop.js` frame의 "멈춤" 조건(시트·VS·결과·리뷰 등)을 한 곳에, `80-input.js` 파워·다이얼 상태 정리, `54-ranked.js` 상태 흐름.
- **S3-b `07-net.js`**: 193줄 클로저를 역할별로.
- **P3-a**: 이름·주석 일관성, 새 부분(영수증 돈 줄, 레이팅 단계 계산)에 검사 더하기.
- **O3-a 인게임 렌더**: 프레임당 할당(GC), 정적 레이어 재사용, 그림자, draw call — `frames.js` md5 그대로.
- **O3-b 메모리**: 게임 5번 들어갔다 나오기 힙 증가, 텍스처·캔버스·렌더러 해제.
- **마무리**: 전체 재측정, 기준과 비교표를 이 파일에, HANDOFF 갱신, 소유자에게 요약.
