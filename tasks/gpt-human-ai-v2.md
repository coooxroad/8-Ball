# 대역 AI: 샷 습관, 조작 실수와 경기 흐름

## 적용 범위

기존 훈련용 난이도 0~3, 물리·규칙·보상 금액·20초 매칭 조건은 유지한다. 대역의 세 축(성격·다마 기반 실력·스타일)을
유지하면서 스타일 6종을 추가한다. 스타일 ID와 기존 방의 persona는 계속 읽을 수 있다.

- 성격 6종 × 스타일 12종 = 72조합. 실력은 연속값이다.
- 새 스타일: `gather`, `draw`, `follow`, `natural`, `position`, `showman`.
- 같은 사람에게 두께·세기·회전·쿠션·포지션 숙련도와 일정한 두께/세기/뱅크 오판 성향이 있다.
  평균 다마가 같아도 장단점이 다르다. 닉네임의 거친 정도와 실력/성격을 직접 연결하지 않는다.

## 샷 선택

모든 다마·스타일이 스턴·밀기·끌기·좌우 회전을 검토한다. 예전 `style.spin > 0.4` 제한은 없다.
회전파는 복합 회전도 검토한다. 맛세이파/묘기파는 세운 큐와 옆 회전을 함께 사용한 후보를 더 찾는다.
`masse: false`인 판에서는 세우지 않는다.

경로마다 회전 후보를 번갈아 시뮬레이션하고, 첫 득점 하나를 찾았다고 탐색을 끝내지 않는다.
후보 전체를 무제한 탐색하지 않고 예산을 제한한다. 8볼/9볼에서는 목적구를 쿠션에 보내는 뱅크와 수구가 먼저 쿠션에
가는 킥을 구분한다. 캐롬은 스턴/자연각 방향과 반사된 목적구를 기준으로 후보를 고른다.

실제 게임 물리로 복사한 테이블을 굴려 득점·파울·다음 배치를 평가한다. 캐롬의 다음 배치는 두 목적구의 거리,
진입 가능성·배치 각도·수구의 쿠션 밀착을 같이 보며 모아치기파는 세 공의 모임도 더 중시한다.
개인별 두께 편향과 뱅크 길이 오판, 세기/회전 전달 오차는 최종 샷에 반영된다.
고급 기술을 좋아하는 것과 잘하는 것은 서로 다른 값이다. 이는 현실 선수 데이터로 학습한 모델은 아니다.

## 준비 동작

`preShot`은 순수 데이터이며 프레임 속도에 따라 난수를 더 소비하지 않는다. 마지막 방향·당점·세기·높이는 실제 샷과 같다.

| 동작 | 초기 설정 |
|---|---|
| 탭 실수 후 정정 | 턴당 `0.008 + (1 - dexterity) × 0.035`, 산만함은 0.015 추가 |
| 당기다 취소/재조준 | `hesitation × 0.16`, 어려운 샷이면 0.035 추가 |
| 큐 흔들기 | `taunt × 0.18`; 장난기는 기존 매 샷 80%에서 14.4%로 낮춤 |
| 작은 재검토 | 위 동작이 없을 때 `hesitation × 0.3` |

한 번의 준비에서 주동작은 하나만 고른다. 조작 실수는 기본적으로 수정하고 친다.
큐를 당겼다 놓는 동작은 세기 UI에도 보인다. 공 위치 변경은 실제 `pos`가 허용되는 볼 인 핸드/브레이크에서만 하며,
각 위치는 미리 `isFree`를 통과한 후보다. 캐롬에서 조준을 다시 한다고 공을 옮기지 않는다.

## 경기 흐름과 기권

최근 자기 샷 수·성공 수·연속 실패·긴장·잠깐의 패작 상태를 `humanState`로 돌려준다. 앱이 Worker의 답을 채택할 때 한 번만
저장하며 다음 요청에 넘긴다. persona나 실제 테이블은 계획 중 바꾸지 않는다. 새 경기를 시작하면 상태를 비운다.

기권/패작의 공통 조건은 총 6샷 이상, 자신의 3샷 이상이며 다음 중 하나를 만족하는 크게 밀린 배치다.

- 캐롬: 상대가 목표의 70% 이상, 점수 차이가 3점 이상.
- 8볼: 그룹이 정해졌고 상대 공은 2개 이하, 내 공은 상대보다 3개 이상 많음.
- 9볼: 상대 성공 수가 4회 이상 많고 최저 목적구가 7 이상, 자신의 연속 실패가 2회 이상.

열세 정도와 개인의 끈기·긴장·공격성을 함께 사용한다. 기권 확률은 조건을 만족하는 자기 턴당 최대 1.705%,
새 패작 진입은 최대 3.355%다. 불리한 매 턴이 아니라 상태 변화 후 최소 4샷 간격을 두며,
패작은 2회의 자기 턴 이내로 짧게 유지하고 열세가 없어지면 해제한다. 끈기 최대값은 끝까지 정상 진행한다.
기권은 `humanCanResign`이 켜진 랭킹 대역에만 허용한다. 값은 현실 통계가 아닌 첫 튜닝값이다.

다마 30/성급함/끈기 0.45, 5점제 0:4, 샷 수 4:7인 동일 조건을 20,000개 씨앗으로 검사한 결과:
기권 0.495%, 패작 2.845%, 정상 진행 96.66%. 경기 전체 기권율을 뜻하지 않는다.

기권은 별도 샷이나 로컬 승리로 위장하지 않는다. 앱이 `{ t: 'resign', as: 1 }`을 보내고 서버가 기존 기록을 재검증해
기권한 대역을 패배 처리한다. `as` 대리 처리는 대역 방의 실제 플레이어 좌석에만 허용한다.
사람끼리의 방에서 상대 좌석으로 기권을 보내도 보낸 사람이 기권한 것으로 처리한다.

## 닉네임

`52-names.js`에 짧은 이름·호칭·일반 명사·영문 계정·일상 문구·당구 별명·거친 표현의 7가지 작명 습관이 있다.
숫자는 선택적으로 붙이고, 밑줄은 일부 영문형만 쓴다. 거친 표현은 요청에 맞춘 수작업 어휘 약 6%다
(`ㅅㅂ또키스`, `존나안맞네` 등의 조합; 외부 이용자의 실제 닉네임은 수집하지 않음).
이름은 16자 이하이며 일반 이름, 숫자 없는 이름과 영문 계정도 섞인다. 중복 없는 실계정 풀은 아니다.

## 검증

- 필수 네 가지: `node web/test/run.js`, `sh web/build.sh`, `node web/tools/check.js`, `node web/test/browser/smoke.js`.
- `node web/test/ai-human.js`: 72조합·4종목, 결정성·기존 persona·각도/당점 범위·물리/원본 불변·실력 차이·성능 상한.
- `node web/test/ai-human-behavior.js`: 이름 10,000개, 확률 20,000회, 초반/접전/끈기/재발 간격, 저다마 회전,
  수정된 탭·조준 취소, Worker의 감정 상태 전달·이전 경기 상태 누출 방지.
- `CHROME=<chromium> node web/test/browser/human-ai.js`: 실제 Worker, 큐/회전 UI, 취소·재조준·합법적인 위치 변경,
  서버 결과를 기다리는 대역 기권과 결과 화면. 라이브 계정이나 보상 요청은 하지 않는다.
- `cd server && npm test`: 대역/사람 방의 기권 좌석과 지급, 새 AI의 회전 샷을 4종목 경기 기록으로 재검증.

실제 Android 기기에서의 손맛·속도와, 당구 경험자가 느끼는 자연스러움은 별도 확인이 필요하다.
