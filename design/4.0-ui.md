# CUE 4.0 화면 설계 — "한 곳의 당구장"

이 문서는 4.0 화면을 만들기 위한 설계서다. 그림을 그리는 대신, 무엇을 어디에 왜 두는지와 그것을 지키는 규칙을 정한다. 세밀한 그림(배경, 소품, 아이콘)은 나중에 이미지 생성으로 만들어 붙인다. 그때도 이 문서의 규칙을 그대로 따른다.

---

## 0. 왜 지금 화면이 "AI 같아" 보이나

지금 로비(2.0.59)가 남이 만든 템플릿처럼 보이는 이유는 이렇다. 4.0에서는 아래 것을 쓰지 않는다.

| 흔한 패턴 | 왜 문제인가 | 4.0에서는 |
|---|---|---|
| 반투명 유리 패널(블러) | 어디에나 쓰여서 아무 게임도 아닌 느낌 | 실제 재료(천, 나무, 공, 초크)만 쓴다 |
| 빛나는 그라데이션 버튼, 반짝임 | 주목을 억지로 끈다 | 버튼은 "눌리는 물건"처럼 생긴다 |
| 종목마다 다른 무지개색 | 색이 많을수록 싸 보인다 | 강조색은 초크 블루 하나뿐이다. 종목의 개성은 공 자체의 색으로 낸다 |
| 둥근 카드 + 선 아이콘 + 짧은 설명 | 모든 앱이 이렇게 생겼다 | 당구장에 실제로 있는 물건이 곧 UI다 |
| 그림자가 제각각 | 빛이 어디서 오는지 모른다 | 그림자는 전부 바로 위 램프에서 수직으로 떨어진다 |
| 화면마다 다른 움직임 | 손에 붙지 않는다 | 모든 움직임이 공의 물리를 따른다 |

---

## 1. 콘셉트: 화면이 아니라 "한 곳의 당구장"

앱 전체가 당구장 한 곳이다. 메뉴는 페이지가 아니라 **당구장 안의 자리**다. 다른 메뉴로 가는 것은 **시선(카메라)이 그 자리로 옮겨 가는 것**이다.

```
            [ 벽: 큐 걸이 ]            [ 벽: 칠판 ]
                 큐 가방                    전적
                    ↖                       ↗
   [ 카운터 ]  ←   [ 내 테이블 (로비) ]   →  [ 홀: 다른 테이블들 ]
     설정                 ↓                     온라인 대전
                    [ 테이블로 다가감 ]
                         경기
```

- **내 테이블 = 로비.** 앱을 켜면 램프 아래 내 테이블 앞에 서 있다.
- **큐 걸이 = 큐 가방.** 왼쪽 벽에 큐가 걸려 있다. 고르면 큐를 벽에서 빼 든다.
- **칠판 = 전적.** 오른쪽 벽 칠판에 이름별 승패가 분필로 적혀 있다.
- **카운터 = 설정.** 입구 쪽 카운터에서 소리·화질 같은 것을 바꾼다.
- **홀 = 온라인 대전.** 다른 테이블들의 불이 켜져 있으면 지금 치고 있는 사람들이다. 빈 테이블에 앉으면 매칭된다.

사람은 "어느 화면에 있었나"보다 "어디에 갔었나"를 훨씬 잘 기억한다. 공간이 곧 메뉴 구조라서, 한 번 둘러보면 다시는 찾을 일이 없다. 체스닷컴에서 겪은 "찾아야 보이는 버튼" 문제를 구조로 없애는 방법이다.

**구현 방식 (렉 없이):** 당구장 전체를 실시간 3D로 그리지 않는다. 자리마다 이미지 생성으로 만든 배경 한 장(같은 조명, 같은 렌즈)을 두고, 자리를 옮길 때는 배경을 가로로 밀면서 테이블만 3D로 움직인다. 앞·중간·뒤 세 겹으로 나눈 시차 효과로 공간감을 낸다. 실시간으로 그리는 건 지금처럼 테이블과 공뿐이다.

## 2. 원칙 다섯 가지

1. **물건이 곧 버튼이다.** 당구장에 있는 물건(공, 큐, 초크, 주판, 칠판)이 그 기능을 맡는다. 물건이 없는 기능은 만들지 않거나, 가장 가까운 물건에 붙인다.
2. **한 화면, 한 행동.** 화면마다 주된 행동은 하나뿐이고, 언제나 같은 자리에 있다. 가로는 오른쪽 아래, 세로는 맨 아래, 엄지가 닿는 곳이다.
3. **처음 오는 사람은 두 번, 다시 오는 사람은 한 번.** 처음 하는 사람은 종목을 누르고 시작을 누르면 된다. 돌아온 사람에게는 지난번 설정 그대로 "한 판 더"가 첫 화면에 있다.
4. **빛은 하나다.** 램프는 테이블 바로 위에 있다. 모든 그림자는 아래로만 떨어지고, 모든 하이라이트는 위쪽에 있다. 화면 어디서도 이 규칙을 어기지 않는다.
5. **움직임은 공처럼.** 멈출 때는 천의 마찰처럼 부드럽게 서고, 부딪힐 때만 아주 작게 튄다. 아무 이유 없이 튀거나 빛나는 움직임은 없다.

## 3. 디자인 토큰

### 3.1 색 — 재료에서 가져온 색만 쓴다

| 이름 | 값 | 재료 | 쓰는 곳 |
|---|---|---|---|
| 홀 | `#0F1012` | 불 꺼진 당구장 | 배경 |
| 그늘 | `#17181B` | 테이블 밖 바닥 | 기본 표면 |
| 레일 | `#2A1C14` → `#4A3022` | 테이블 나무 레일 | 프레임, 테두리 (넓은 면에는 쓰지 않음) |
| 아이보리 | `#F3EEE3` | 흰 공 | 주 글자색 (순백 `#FFF`은 쓰지 않음) |
| 회색 분필 | `#A9A496` | 칠판 분필 | 보조 글자 |
| **초크 블루** | `#4F8BD0` (눌림 `#3B72B3`) | 큐 초크 | **유일한 강조색.** 선택, 포커스, 주된 행동 |
| 펠트 | 테이블 천 색 | 천 | 테이블과 그 위에 놓인 것만 |
| 황동 | `#C7A158` | 램프, 레일 금속 | 보상, 기록 경신, 프리미엄 (드물게) |
| 공 빨강 | `#D3241C` | 4구 빨간 공 | 파울, 패배, 경고 |

- 종목의 개성은 공의 색으로만 낸다. 8볼은 검은 공, 9볼은 노란 공, 4구는 빨간 공, 3구는 노란 공이다. 버튼이나 배경을 종목 색으로 칠하지 않는다.
- 초크 블루는 한 화면에 한두 곳만 쓴다. 많아지면 아무것도 강조되지 않는다.

### 3.2 글자

- 글꼴은 지금 앱의 것을 그대로 쓴다. 한글은 Gothic A1, 숫자는 Outfit이다. 새 글꼴을 들이지 않는다.
- 크기 단계: **13 / 15 / 17 / 22 / 28 / 40**. 이 밖의 크기는 쓰지 않는다.
- 본문 최소 15. 중장년층을 위해 13은 보조 정보에만 쓴다.
- 굵기: 500(본문), 700(이름, 버튼), 800(제목). 300은 쓰지 않는다.
- 숫자(점수, 수지, 세기)는 언제나 Outfit, 고정폭 숫자로 써서 바뀔 때 흔들리지 않게 한다.

### 3.3 간격과 크기

- 4의 배수만 쓴다: 4, 8, 12, 16, 24, 32, 48.
- 누르는 것은 최소 48×48.
- 둥글기 단계: **공**은 완전한 원, **초크·버튼**은 10, **레일 프레임**은 4. 이 세 가지뿐이다. 둥글기가 재료를 말해 준다.

### 3.4 그림자 — 램프 하나

- 위에서 떨어지는 그림자 한 종류만 쓴다: `0 Ypx Bpx rgba(0,0,0,a)`. 들린 정도(높이)에 따라 Y, B, a만 커진다.
- 높이 1(놓여 있음) `0 2 4 .4`, 높이 2(들림) `0 6 14 .45`, 높이 3(손에 듦) `0 14 28 .5`.
- 가로 방향 그림자, 색 있는 그림자, 바깥 글로우는 쓰지 않는다.

### 3.5 움직임

| 이름 | 길이 | 곡선 | 쓰는 곳 |
|---|---|---|---|
| 손끝 | 90ms | ease-out | 누르는 순간 눌림 (2px 아래, 그림자 줄어듦) |
| 굴러 섬 | 260ms | `cubic-bezier(.2,.7,.2,1)` (마찰로 서는 공) | 선택 이동, 패널 열림 |
| 자리 이동 | 520ms | `cubic-bezier(.45,0,.2,1)` | 당구장 안에서 시선 옮기기 |
| 부딪힘 | 140ms | 2px 튀고 원위치 | 공이 무언가에 닿을 때만 |

- 아무것도 깜빡이거나 숨 쉬듯 반복하지 않는다. 예외는 하나, 온라인 대기 중 "초크칠"뿐이다.
- 시스템의 "움직임 줄이기"가 켜져 있으면 자리 이동은 즉시 바뀌는 페이드로 대신한다.

### 3.6 소리와 진동 — 당구장 소리만

| 행동 | 소리 | 진동 |
|---|---|---|
| 아무 버튼 누름 | 초크가 큐 팁에 닿는 작은 "틱" | 아주 짧게 |
| 선택 바뀜 | 공 두 개가 가볍게 "딱" | 짧게 |
| 경기 시작 | 브레이크 (공이 흩어지는 소리) | 중간 |
| 닫기·뒤로 | 공이 포켓에 떨어지는 "툭" | 없음 |
| 잘못된 행동 | 미스큐 소리 | 두 번 짧게 |
| 기록 경신·보상 | 황동 램프 줄이 "찰랑" | 길게 한 번 |

전자음, 효과음 라이브러리 소리는 쓰지 않는다. 전부 직접 녹음하거나 지금처럼 코드로 합성한 당구 소리다.

## 4. 화면별 설계

### 4.1 로비 — 내 테이블 앞

**가로(태블릿)**

```
┌──────────────────────────────────────────────────────────────────┐
│ 큐 걸이 ◂                                                ▸ 칠판   │ ← 양쪽 벽 끝이 살짝 보임(누르면 그 자리로)
│                                                                    │
│            ( 램프 )                                               │
│      ┌──────────────────────────────┐        ┌────────────────┐  │
│      │                              │        │ 이어서 하기     │  │
│      │        내 테이블 (3D)         │        │ 4구 · 민수와    │  │
│      │      종목에 맞게 공이 놓임     │        │ 20 : 10         │  │
│      │                              │        ├────────────────┤  │
│      └──────────────────────────────┘        │ 상대  친구 ▸    │  │
│                                                │ 점수  주판 ●●●○ │  │
│   ● 8볼   ● 9볼   ●● 4구   ●●● 3구   │ 퍼즐 레슨 │ 장비  큐·조준선 │  │
│   └─ 테이블 레일 위에 공이 놓인 선반 ─┘          │ [  치러 가기  ] │  │
└──────────────────────────────────────────────────────────────────┘
```

- **종목 고르기 = 공 선반.** 테이블 아래 레일 위에 종목 공이 놓여 있다. 공을 누르면 그 공이 테이블 쪽으로 굴러가고, 테이블 위 배치가 그 종목으로 바뀐다. 지금 고른 공만 램프 빛을 받고 나머지는 그늘에 있다. 색 테두리나 체크 표시는 없다. **빛이 곧 선택 표시다.**
- **퍼즐·레슨**은 같은 선반 오른쪽 끝, 나무 칸막이 너머에 둔다. "혼자 하는 것"이라는 구분을 칸막이 하나로 보여 준다.
- **오른쪽 = 점수판.** 당구장 벽에 걸린 점수판처럼 생긴 판 하나에 경기 설정을 모은다.
  - 맨 위는 **이어서 하기**다. 하던 판이 있을 때만 있고, 있으면 이게 주된 행동이 된다.
  - **상대:** 친구 / 컴퓨터. 컴퓨터를 고르면 그 자리에서 난이도 공 네 개(흰·노랑·주황·빨강)가 나온다.
  - **점수:** 4구·3구는 **주판**이다. 알을 밀어 목표 점수나 수지를 정하고, 눌러도 된다. 한국 당구장 사람이면 설명 없이 안다.
  - **장비:** 지금 큐의 작은 그림과 조준선 길이. 누르면 큐 걸이로 간다.
- **주된 행동 "치러 가기":** 버튼은 큐 끝(팁)처럼 생겼다. 누르면 큐가 흰 공을 치는 소리와 함께 시선이 테이블로 다가가며 경기가 시작된다. 시작 연출 자체가 버튼의 대답이다.
- **돌아온 사람:** 지난번과 같은 설정이면 버튼 문구가 "한 판 더 · 4구 민수와"가 된다. 한 번 누르면 끝난다.

**세로(폰·세로 태블릿):** 위에서 아래로 테이블 → 공 선반(가로로 밀림) → 점수판 → 버튼(화면 맨 아래 고정) 순서다. 벽 자리(큐 걸이, 칠판, 카운터)는 맨 위 왼쪽·오른쪽 끝의 작은 그림 버튼으로 간다.

### 4.2 경기 화면

지금 구조(왼쪽 큐 당기기, 오른쪽 미세 조준, 오른쪽 아래 당점)는 손에 잘 맞으니 유지하고 재료만 바꾼다.

- **점수판 = 테이블 위쪽 레일.** 화면 위에 뜬 알약 모양 대신, 테이블 레일에 붙은 나무 점수판이다.
  - 4구·3구는 주판알이 득점마다 "탁" 하고 밀린다.
  - 8볼·9볼은 넣은 공이 레일 홈에 줄 지어 굴러 들어간다.
- **차례 표시:** 차례인 사람 쪽 램프가 켜진다. 색 테두리가 아니라 빛이다.
- **세기:** 큐를 당기는 지금 방식을 유지한다. 힘이 세질수록 색이 바뀌는 대신 큐가 더 깊이 당겨지고 팁의 초크가 더 또렷해진다.
- **당점:** 흰 공 얼굴을 유지한다. 위에 초크 자국(파란 점)이 찍힌다.
- **멈춤 메뉴:** 화면을 가리는 시트 대신 큐를 내려놓는 동작이다. 테이블이 살짝 어두워지고 테이블 위에 선택지 세 개(계속 / 다시 / 로비로)가 놓인다.

### 4.3 결과 — 칠판에 적힘

- 경기가 끝나면 시선이 칠판으로 옮겨 가고, 분필로 이번 판이 적힌다.
  - 4구·3구: 점수, 이닝, 에버리지, 하이런
  - 포켓볼: 넣은 공, 파울
- 이긴 쪽 이름 옆에 황동 핀이 꽂힌다. 연승이면 핀이 늘어난다.
- 하이라이트는 칠판 아래 사진처럼 꽂힌 카드다. 누르면 그 장면이 다시 나온다.
- 주된 행동은 "한 판 더", 오른쪽 아래.

### 4.4 큐 걸이 — 큐 가방

- 벽에 큐가 세로로 걸려 있다. 가로로 밀어서 고른다.
- 고른 큐는 벽에서 빠져 나와 확대되고, 팁·페럴·조인트·버트를 따라 손가락으로 훑어볼 수 있다.
- 큐의 이름과 한 줄 이야기만 있고 능력치 막대는 없다. 온라인 공정성을 위해 큐는 외형만 다르다.
- 예외로 점프 큐는 벽 따로 칸에 건다.

### 4.5 칠판 — 전적

- 이름별로 분필 글씨: 승·패·연승·에버리지.
- 연승 중이면 이름 옆에 불꽃 대신 **바를 정(正) 자 줄긋기**로 연승을 센다. 칠판에 분필로 셀 때 우리가 실제로 쓰는 방식이라, 칠판이라는 물건과 맞는다.
- 지우기는 칠판지우개를 길게 누르기다. 실수로 지울 수 없다.

### 4.6 카운터 — 설정

- 카운터 위에 물건이 놓여 있다.
  - 소리 = 라디오 스위치
  - 화질 = 램프 밝기 손잡이
  - 빠른 진행 = 모래시계
  - 하이라이트 노래 = 카세트
  - 첫 화면 되돌리기 = 맨 아래 작은 글자
- 물건 아래 짧은 이름표가 있다. 중장년층도 글자로 찾을 수 있다.

### 4.7 홀 — 온라인 대전 (4.0)

- 홀에 테이블 여러 개가 있고, 불 켜진 테이블에서는 누군가 치고 있다. 그 위에 이름표와 종목이 떠 있다.
- **빠른 대전:** 빈 테이블 하나가 밝아지며 "앉기"가 뜬다. 누르면 매칭을 시작한다.
- 매칭을 기다리는 동안 내 캐릭터 손이 큐에 초크를 칠한다. 이것이 유일한 반복 애니메이션이다.
- **친구 방:** 테이블 번호표에 방 코드가 적혀 있다.

## 5. 처음 오는 사람의 흐름

1. 앱을 켜면 내 테이블 앞이다. 램프가 켜지는 연출이 0.6초 나온다(처음 한 번만).
2. 공 선반의 8볼이 이미 빛을 받고 있고, 테이블 위에 8볼 배치가 놓여 있다.
3. 화면에 글자 안내는 하나뿐이다: "치러 가기를 누르세요". 손가락 그림이나 말풍선은 없다.
4. 첫 경기에서 첫 샷 때만 큐를 당기는 손 그림자가 한 번 지나간다.
5. 첫 판이 끝나면 칠판에 이름이 처음 적힌다. "이름을 바꾸려면 칠판의 이름을 누르세요."

## 6. 글 쓰는 법

- 존댓말, 짧게. 당구장 사장님이 손님에게 하는 말투를 기준으로 한다. 친절하지만 길게 설명하지 않는다.
- 버튼은 동사로 끝낸다: 치러 가기, 한 판 더, 이어서 하기, 큐 고르기.
- 당구 용어는 한국 당구장에서 쓰는 말 그대로 쓴다: 수지, 하이런, 에버리지, 맛세이, 끌어치기.
- 느낌표와 이모지는 쓰지 않는다.

## 7. 이미지 생성으로 만들 것 (나중에)

모든 그림은 같은 촬영 조건으로 만든다. 아래 기준 문장을 모든 프롬프트 앞에 붙인다.

> 기준: 밤의 한국 당구장 실내, 테이블 바로 위 따뜻한 텅스텐 램프 하나만 켜짐, 주변은 어둡게 떨어짐, 50mm 렌즈, 눈높이보다 약간 위, 얕은 심도, 사실적이지만 부드러운 질감, 브랜드·글자·로고 없음, 색: 짙은 나무, 황동, 청록 천, 아이보리.

| 그림 | 크기 | 메모 |
|---|---|---|
| 자리별 배경: 내 테이블, 큐 걸이 벽, 칠판 벽, 카운터, 홀 | 가로 2732×2048, 세로 2048×2732 | 테이블 자리는 비워 둔다 (3D 테이블이 들어감). 앞·중간·뒤 세 겹으로 나눠 받는다 |
| 큐 12종 | 세로로 긴 투명 배경 | 정면, 같은 조명 |
| 소품: 초크, 주판, 황동 핀, 칠판지우개, 라디오, 램프 손잡이, 모래시계, 카세트 | 정사각 투명 배경 | 같은 각도(위에서 30°) |
| 앱 아이콘 | 1024×1024 | 램프 빛 아래 공 하나와 초크 자국. 글자 없음 |

그림이 오기 전까지는 지금 코드로 그린 단색 모양을 자리표시로 쓴다. 구조와 동작은 그림 없이 먼저 완성한다.

## 8. 만드는 순서

| 단계 | 내용 | 확인 방법 |
|---|---|---|
| 1 | 디자인 토큰을 코드로 옮김 (색, 글자, 간격, 그림자, 움직임, 소리) | 지금 화면이 토큰만으로 다시 칠해짐 |
| 2 | 로비: 공 선반, 점수판, 주판, "치러 가기"와 시작 연출 | 태블릿 가로·세로, 폰에서 직접 |
| 3 | 자리 이동 틀 (배경 밀기 + 테이블 카메라), 자리표시 배경으로 | 큐 걸이·칠판·카운터를 오갈 때 끊김이 없는지 |
| 4 | 경기 화면 재료 바꾸기 (레일 점수판, 램프 차례 표시) | 경기 중 프레임 |
| 5 | 결과 칠판, 큐 걸이, 카운터 | |
| 6 | 그림 붙이기 (이미지 생성) | 같은 조명, 같은 각도인지 |
| 7 | 홀(온라인)은 서버와 함께 | |

모든 단계에서 설정의 "첫 화면: 이전 화면"으로 지금 화면에 돌아갈 수 있게 둔다. 각 단계는 따로 커밋해서 하나씩 되돌릴 수 있게 한다.
